# Engineering Lessons Learned (Fehlerklassen & Schutzmechanismen)

This document summarizes recurring GBA Gen-3 localization failure classes discovered during real-world multi-megabyte translation projects and maps each class to the Glyphwerk module/gate that prevents it.

| Failure Class | Root Cause | Symptom in Game | Glyphwerk Prevention |
|---|---|---|---|
| **1. `RANDOM_PTR_IN_GFX`** | A naive pointer scanner mistakes a coincidental `0x08xxxxxx` 4-byte word inside compressed LZ77 tile/palette/map-border data for a text pointer and retargets it. | Garbled battle backgrounds, corrupted map borders, broken UI tiles. | `glyphwerk.rom.relocate.graphic_lock_ranges()` + `glyphwerk.gates.gfx_pointers` + `PointerBlocklist`. |
| **2. `TABLE_BASE_LITERAL`** | A Thumb function loads a fixed-stride struct table via `ldr rB, =sTable` and indexes it via `lsls`/`muls` + `adds`. Retargeting the literal to a single relocated string breaks every table entry. | Wrong species names, corrupted trade NPCs, Pokédex freezes. | `glyphwerk.rom.table_guard.detect_table_base_literals()` + In-Place-First policy (`glyphwerk.porter.tables`). |
| **3. `STRCPY_00_SPACE`** | Native code calls C `libc strcpy` (terminates at `0x00`) on a Gen-3 PCS string where `0x00` is the **space** character. Translating `"Go back"` (space at byte 2) to `"Zurückgehen"` (no space) copies far beyond the stack buffer. | Hard crash / corrupted return address in specific dialogs or menus. | `glyphwerk.gates.strcpy_safety.check_strcpy_safety()`. |
| **4. `CONTROL_CODE_ARGS`** | Decoding `0xFC` color/font/pause commands without respecting per-subcommand argument lengths (`FC_ARGS`) interprets argument bytes as visible text or drops them on roundtrip. | Missing colors, garbled characters, broken dialog pauses. | `glyphwerk.codec.pcs.FC_ARGS` + lossless `encode(decode(b)) == b`. |
| **5. `PREFIX_COLLISION_P`** | Longest-prefix matching reads `\pkönnen` as the `\pk` glyph prefix instead of page break `\p` (`0xFB`) + `können`. | Missing page breaks and swallowed initial letters. | `glyphwerk.codec.pcs.encode()` treats `\p` unconditionally as `0xFB` except exact `\pk\mn`. |
| **6. `PRECEDING_TERMINATOR`** | Allocating relocated strings starting at byte `+0` of a `0xFF` run overwrites the `0xFF` terminator of the immediately preceding string. | Unrelated previous dialog bleeds directly into the newly relocated text. | `PoolAllocator(..., terminator_guard=2)`. |
| **7. `UNALIGNED_XSE_PTRS`** | Scanning only 4-byte-aligned words misses unaligned XSE script operands (`0x0F loadpointer`, `0x67 msgbox`, `0x85 bufferstring`, `0x5C trainerbattle`). | Translations appear "missing" in diagnostics or get orphaned on port. | `glyphwerk.rom.pointers.find_unaligned_xse_pointers()` + `find_all_pointers()`. |
| **8. `BORDER_CLIP_230PX`** | Centered Pokédex windows (240 px wide) reserve 4–5 px on each side for decorative frames; wrapping to 240 px clips text into the border. | First/last letters touching or overlapping the gray frame. | `glyphwerk.porter.dex_wrap.wrap_balanced(..., max_line_px=230, max_lines=3)`. |
| **9. `DOUBLE_SCROLL_AND_GLUED_BUF`** | Copy-edit typos produce `\llist` instead of `\list` (while `\llieber` = `\l` + `lieber` is valid!) or drop the space after `[#FD01]`. | Visible extra `"l"` at line start or glued stat names in battle. | `glyphwerk.gates.text_diff.check_text_entry()`. |
| **10. `STATIC_NPC_BLOCKER`** | An automated playtest bot treats every map NPC coordinate as permanently solid even after story flags hide the NPC. | Bot loops endlessly on early maps and misses downstream story scenes. | `glyphwerk.bot.router.LiveFlags` + `WorldGraph.is_npc_blocking()` + fail-closed `ScriptWarp`. |
